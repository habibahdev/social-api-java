# SocialAPI

API REST de réseau social - puliccation, commentaire, liker avec authentification JWT.
Version Java de mon [API REST](https://github.com/habibahdev/social-api) développée en PHP.
 ---

## Stack

- Java 21
- Spring Boot
- MySQL 8.4
- JWT
- Docker & Docker COmpose

---

## Démarrer

```bash
docker compose up --build
```

 - Application disponible sur `http://localhost:8081`
 - Documentation Swagger UI disponible sur `http://localhost:8081/swagger`
